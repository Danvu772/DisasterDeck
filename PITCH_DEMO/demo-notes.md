# Pitch demo: what works right now

Recorded walkthrough with Darshal, 15 Nov 2026. This is the click path that is known to work, in demo order.

## 1. Agent

- Ask about shelter capacity. The agent answers and generates charts.
- Ask "where is the shelter?" The map integration is done, so it pops up a map with the shelter on it.

## 2. Ops room

- Open the ops room. Incoming posts show up in a list on the left.

## 3. Coordinator approvals

- Switch to the coordinator view. Posts have approval actions you can press (approve).
- After approving, go into the agent tab. You can view it as different user types.
- Click accept. The state changes, and the item gets added to the task list.

## 4. Field

- Open the field view. You can talk to it: natural language queries by voice.
