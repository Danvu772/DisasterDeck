# D-0008 License: open source under AGPL

- **Date:** 2026-11-17
- **Status:** accepted, pending team agreement
- **Decided by:** Dan Vu (design owner). Ömer to sign off on `docs/SYSTEM_DESIGN.md`
- **Dissent:** none recorded

## Context
The repo has no license, and Darshal, Ömer and others wrote parts of it, so by default they own their code.

## Decision
Publish under AGPL ("open franchising"). Anyone can run or host it. The business sells hosting, setup, training and support. AGPL keeps everyone's improvements public.

## Consequences
Needs every contributor's written agreement before the LICENSE file lands. Then a GitHub organization, a contributor agreement and an AUTHORS file. Publishing under AGPL is also the first step for an NSF PESOSE application.
