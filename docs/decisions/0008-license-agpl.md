# D-0008 License: open source under AGPL

- **Date:** 2026-11-17
- **Status:** accepted
- **Decided by:** Dan Vu (owner, only voter)

## Context
The repo has no license, so by default nobody else may reuse it.

## Decision
Publish under AGPL ("open franchising"). Anyone can run or host it. The business sells hosting, setup, training and support. AGPL keeps everyone's improvements public.

## Consequences
Add a LICENSE file, then a GitHub organization, a contributor agreement for future outside contributors and an AUTHORS file. Publishing under AGPL is also the first step for an NSF PESOSE application.
